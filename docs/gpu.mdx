### GPU 选择

如果你的系统里有多块 NVIDIA GPU,想让 Ollama 只使用其中一部分,可以把 `CUDA_VISIBLE_DEVICES` 设为逗号分隔的 GPU 列表。可以使用数字 ID,但顺序可能变化,因此 UUID 更可靠。运行 `nvidia-smi -L` 可以查看 GPU 的 UUID。如果想忽略 GPU、强制使用 CPU,可填一个无效的 GPU ID(如 "-1")。

### Linux 休眠恢复

在 Linux 上,经过一次挂起/恢复循环后,Ollama 有时会找不到你的 NVIDIA GPU,从而回退到 CPU 运行。可以通过重载 NVIDIA UVM 驱动绕过这个驱动 bug:`sudo rmmod nvidia_uvm && sudo modprobe nvidia_uvm`

### Linux 上的覆盖(Override)

Ollama 使用的 AMD ROCm 库并不支持所有 AMD GPU。某些情况下,你可以强制系统尝试使用一个相近的 LLVM target。例如,Radeon RX 5400 是 `gfx1034`(即 10.3.4),但 ROCm 目前不支持该 target,最接近的支持是 `gfx1030`。你可以使用 `x.y.z` 语法的环境变量 `HSA_OVERRIDE_GFX_VERSION`。例如,要强制系统在 RX 5400 上运行,就把服务端的环境变量设为 `HSA_OVERRIDE_GFX_VERSION="10.3.0"`。如果你的 AMD GPU 不受支持,可以参照下方支持类型列表做实验。

如果你有多块 GFX 版本不同的 GPU,可以在环境变量后追加数字设备编号来分别设置。例如 `HSA_OVERRIDE_GFX_VERSION_0=10.3.0` 和 `HSA_OVERRIDE_GFX_VERSION_1=11.0.0`。

### GPU 选择

如果你的系统里有多块 AMD GPU,想让 Ollama 只使用其中一部分,可以把 `ROCR_VISIBLE_DEVICES` 设为逗号分隔的 GPU 列表。用 `rocminfo` 可以查看设备列表。如果想忽略 GPU、强制使用 CPU,可填一个无效的 GPU ID(如 "-1")。在可用的情况下,请使用 `Uuid` 而不是数字值来唯一标识设备。

### 容器权限

在某些 Linux 发行版上,SELinux 会阻止容器访问 AMD GPU 设备。可在宿主机上运行 `sudo setsebool container_use_devices=1`,允许容器使用设备。

## Vulkan GPU 支持

Windows 和 Linux 上的额外 GPU 支持由 [Vulkan](https://www.vulkan.org/) 提供。后端安装后 Vulkan 默认启用。在 Windows 上,大多数 GPU 厂商的驱动都自带 Vulkan 支持,无需额外步骤。大多数 Linux 发行版需要安装额外组件,且 Vulkan 驱动可能有多种选择,包括 Mesa 和 GPU 厂商专用包:

- Linux Intel GPU 指引 - https://dgpu-docs.intel.com/driver/client/overview.html
- Linux AMD GPU 指引 - https://amdgpu-install.readthedocs.io/en/latest/install-script.html#specifying-a-vulkan-implementation

对某些 Linux 发行版上的 AMD GPU,你可能需要把 `ollama` 用户加入 `render` 组。

Ollama 调度器会利用 GPU 库上报的可用显存数据来做最优调度决策。Vulkan 需要额外的能力(capability)或以 root 运行才能暴露可用显存数据。如果既没有 root 权限也没有该能力,Ollama 会用模型的近似大小来尽力做出调度决策。

```bash
sudo setcap cap_perfmon+ep /usr/local/bin/ollama
```

### GPU 选择

要选择特定的 Vulkan GPU,可以按 [FAQ](faq#how-do-i-configure-ollama-server) 所述,把 Ollama 服务端的环境变量 `GGML_VK_VISIBLE_DEVICES` 设为一个或多个数字 ID。如果 Vulkan GPU 出现问题,可以设置 `OLLAMA_VULKAN=0` 或 `GGML_VK_VISIBLE_DEVICES=-1` 禁用所有 Vulkan GPU。

在 iGPU/dGPU 混合系统上,如果 Vulkan iGPU 不稳定,保持 Vulkan 启用,并把 `GGML_VK_VISIBLE_DEVICES` 设为独立显卡的索引。例如,当 `Vulkan1` 是独立 GPU 时,使用 `GGML_VK_VISIBLE_DEVICES=1`。
