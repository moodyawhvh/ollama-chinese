## 格式

`Modelfile` 的格式:

```
# comment
INSTRUCTION arguments
```

| 指令                                | 说明                                       |
| ----------------------------------- | -------------------------------------------------------------- |
| [`FROM`](#from必需)(必需)          | 定义要使用的基座模型。                 |
| [`PARAMETER`](#parameter)           | 设置 Ollama 运行模型时的参数。         |
| [`TEMPLATE`](#template)             | 发送给模型的完整提示词模板。              |
| [`SYSTEM`](#system)                 | 指定写入模板中的系统消息。 |
| [`ADAPTER`](#adapter)               | 定义要应用到模型上的 (Q)LoRA 适配器。            |
| [`LICENSE`](#license)               | 指定法律许可证。                                   |
| [`MESSAGE`](#message)               | 指定消息历史。                                       |
| [`REQUIRES`](#requires)             | 指定模型要求的 Ollama 最低版本。   |

## 示例

### 基础 `Modelfile`

一个创建 mario 蓝图的 `Modelfile` 示例:

```
FROM llama3.2
# sets the temperature to 1 [higher is more creative, lower is more coherent]
PARAMETER temperature 1
# sets the context window size to 4096, this controls how many tokens the LLM can use as context to generate the next token
PARAMETER num_ctx 4096

# sets a custom system message to specify the behavior of the chat assistant
SYSTEM You are Mario from super mario bros, acting as an assistant.
```

使用方法:

1. 把它保存为文件(例如 `Modelfile`)
2. `ollama create choose-a-model-name -f <location of the file e.g. ./Modelfile>`
3. `ollama run choose-a-model-name`
4. 开始使用模型!

查看某个模型的 Modelfile,使用 `ollama show --modelfile` 命令。

```shell
ollama show --modelfile llama3.2
```

```
# Modelfile generated by "ollama show"
# To build a new Modelfile based on this one, replace the FROM line with:
# FROM llama3.2:latest
FROM /Users/pdevine/.ollama/models/blobs/sha256-00e1317cbf74d901080d7100f57580ba8dd8de57203072dc6f668324ba545f29
TEMPLATE """{{ if .System }}<|start_header_id|>system<|end_header_id|>

{{ .System }}<|eot_id|>{{ end }}{{ if .Prompt }}<|start_header_id|>user<|end_header_id|>

{{ .Prompt }}<|eot_id|>{{ end }}<|start_header_id|>assistant<|end_header_id|>

{{ .Response }}<|eot_id|>"""
PARAMETER stop "<|start_header_id|>"
PARAMETER stop "<|end_header_id|>"
PARAMETER stop "<|eot_id|>"
PARAMETER stop "<|reserved_special_token"
```

## 指令

### FROM(必需)

`FROM` 指令定义创建模型时要使用的基座模型。

```
FROM <model name>:<tag>
```

#### 从现有模型构建

```
FROM llama3.2
```

<Card title="Model library" href="https://ollama.com/library">
  Browse available models
</Card>

#### 从 Safetensors 模型构建

```
FROM <model directory>
```

模型目录中应包含受支持架构的 Safetensors 权重。

当前支持的模型架构:

- Llama(包括 Llama 2、Llama 3、Llama 3.1 和 Llama 3.2)
- Mistral(包括 Mistral 1、Mistral 2 和 Mixtral)
- Gemma(包括 Gemma 1 和 Gemma 2)
- Phi3

#### 从 GGUF 文件构建

```
FROM ./ollama-model.gguf
```

GGUF 文件位置应使用绝对路径,或相对于 `Modelfile` 所在位置的路径。

### PARAMETER

`PARAMETER` 指令定义模型运行时可以设置的参数。

```
PARAMETER <parameter> <parametervalue>
```

#### 有效参数与取值

| 参数           | 说明                                                                                                                                                                                                                                                                                                                                                                            | 取值类型 | 示例                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | -------------------- |
| num_ctx        | 设置用于生成下一个 token 的上下文窗口大小。(默认:2048)                                                                                                                                                                                                                                                                                           | int        | num_ctx 4096         |
| repeat_last_n  | 设置模型回看多少个 token 来防止重复。(默认:64,0 = 禁用,-1 = num_ctx)                                                                                                                                                                                                                                                                   | int        | repeat_last_n 64     |
| repeat_penalty | 设置对重复内容的惩罚强度。值越高(如 1.5)惩罚越重,值越低(如 0.9)越宽容。(默认:1.0,即禁用)                                                                                                                                                                                                                   | float      | repeat_penalty 1.1   |
| temperature    | 模型的温度。提高温度会让模型的回答更有创造性。(默认:0.8)                                                                                                                                                                                                                                                              | float      | temperature 0.7      |
| seed           | 设置生成时使用的随机数种子。设定为固定数字后,相同提示词会让模型生成相同的文本。(默认:0)                                                                                                                                                                                                                | int        | seed 42              |
| stop           | 设置停止序列。遇到该模式时 LLM 会停止生成并返回。可在 Modelfile 中指定多个独立的 `stop` 参数来设置多个停止模式。                                                                                                                                                 | string     | stop "AI assistant:" |
| num_predict    | 生成文本时最多预测的 token 数。(默认:-1,无限生成)                                                                                                                                                                                                                                                                                    | int        | num_predict 42       |
| draft_num_predict | 存在草稿模型(draft model)时,每步最多预测的投机草稿 token 数。独立草稿模型默认为 4;内嵌 MTP 张量则需要显式设置此参数。设为 0 可禁用投机草稿。                                                                                                                                               | int        | draft_num_predict 4  |
| top_k          | 降低生成无意义内容的概率。值越高(如 100)答案越多样,值越低(如 10)越保守。(默认:40)                                                                                                                                                                                                 | int        | top_k 40             |
| top_p          | 与 top-k 配合工作。值越高(如 0.95)文本越发散,值越低(如 0.5)文本越聚焦保守。(默认:0.9)                                                                                                                                                               | float      | top_p 0.9            |
| min_p          | top_p 的替代方案,旨在兼顾质量与多样性。参数 \_p* 表示一个 token 被纳入考虑的最低相对概率(相对于最可能 token 的概率)。例如 _p_=0.05 且最可能 token 的概率为 0.9 时,logit 值低于 0.045 的候选会被过滤掉。(默认:0.0) | float      | min_p 0.05           |

### TEMPLATE

`TEMPLATE` 是传给模型的完整提示词模板。它可以(可选地)包含系统消息、用户消息和模型的回复。注意:语法可能因模型而异。模板使用 Go 的[模板语法](https://pkg.go.dev/text/template)。

#### 模板变量

| 变量              | 说明                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `{{ .System }}`   | 用于指定自定义行为的系统消息。                                           |
| `{{ .Prompt }}`   | 用户的提示词消息。                                                                      |
| `{{ .Response }}` | 模型的回复。生成回复时,该变量之后的文本会被省略。 |

```
TEMPLATE """{{ if .System }}<|im_start|>system
{{ .System }}<|im_end|>
{{ end }}{{ if .Prompt }}<|im_start|>user
{{ .Prompt }}<|im_end|>
{{ end }}<|im_start|>assistant
"""
```

### SYSTEM

`SYSTEM` 指令指定模板中使用的系统消息(如适用)。

```
SYSTEM """<system message>"""
```

### ADAPTER

`ADAPTER` 指令指定要应用到基座模型上的微调 LoRA 适配器。适配器的取值应为绝对路径,或相对于 Modelfile 的路径。基座模型必须用 `FROM` 指令指定。如果基座模型与适配器调优时使用的基座模型不一致,模型行为会不稳定。

#### Safetensor 适配器

```
ADAPTER <path to safetensor adapter>
```

当前支持的 Safetensor 适配器:

- Llama(包括 Llama 2、Llama 3 和 Llama 3.1)
- Mistral(包括 Mistral 1、Mistral 2 和 Mixtral)
- Gemma(包括 Gemma 1 和 Gemma 2)

#### GGUF 适配器

```
ADAPTER ./ollama-lora.gguf
```

### LICENSE

`LICENSE` 指令用于指定本 Modelfile 所用模型的共享或分发许可证。

```
LICENSE """
<license text>
"""
```

### MESSAGE

`MESSAGE` 指令允许你为模型指定回答时使用的消息历史。通过多条 MESSAGE 命令构建一段对话,引导模型以类似的方式回答。

```
MESSAGE <role> <message>
```

#### 有效角色

| 角色      | 说明                                                  |
| --------- | ------------------------------------------------------------ |
| system    | 为模型提供 SYSTEM 消息的另一种方式。 |
| user      | 用户可能会提出的问题示例。        |
| assistant | 模型应如何回答的示例消息。          |

#### 对话示例

```
MESSAGE user Is Toronto in Canada?
MESSAGE assistant yes
MESSAGE user Is Sacramento in Canada?
MESSAGE assistant no
MESSAGE user Is Ontario in Canada?
MESSAGE assistant yes
```

### REQUIRES

`REQUIRES` 指令允许你指定模型要求的 Ollama 最低版本。

```
REQUIRES <version>
```

版本号应为有效的 Ollama 版本(例如 0.14.0)。

## 注意事项

- **`Modelfile` 不区分大小写**。示例中使用大写指令,是为了更容易与参数区分。
- 指令可以按任意顺序排列。示例中把 `FROM` 放在最前面是为了便于阅读。
