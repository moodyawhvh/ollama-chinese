### 运行模型

```
ollama run gemma4
```

### 启动集成

```
ollama launch
```

配置并启动外部应用来使用 Ollama 模型。这提供了一种交互式方式,设置并启动与受支持应用的集成。

#### 受支持的集成

- **OpenCode** - 开源编码助手
- **Claude Code** - Anthropic 的智能体编码工具
- **Codex** - OpenAI 的编码助手
- **VS Code** - 微软的 IDE,内置 AI 对话
- **Droid** - Factory 的 AI 编码智能体

#### 示例

交互式启动一个集成:

```
ollama launch
```

启动指定的集成:

```
ollama launch claude
```

使用指定模型启动:

```
ollama launch claude --model qwen3.5
```

只配置、不启动:

```
ollama launch droid --config
```

#### 多行输入

多行输入可以用 `"""` 包裹文本:

```
>>> """Hello,
... world!
... """
I'm a basic program that prints the famous "Hello, world!" message to the console.
```

#### 多模态模型

```
ollama run gemma4 "What's in this image? /Users/jmorgan/Desktop/smile.png"
```

### 生成嵌入(embeddings)

```
ollama run embeddinggemma "Hello world"
```

输出是一个 JSON 数组:

```
echo "Hello world" | ollama run nomic-embed-text
```

### 下载模型

```
ollama pull gemma4
```

### 删除模型

```
ollama rm gemma4
```

### 列出模型

```
ollama ls
```

### 登录 Ollama

```
ollama signin
```

### 退出 Ollama 登录

```
ollama signout
```

### 创建自定义模型

首先,创建一个 `Modelfile`

```
FROM gemma4
SYSTEM """You are a happy cat."""
```

然后运行 `ollama create`:

```
ollama create -f Modelfile
```

### 列出运行中的模型

```
ollama ps
```

### 停止运行中的模型

```
ollama stop gemma4
```

### 启动 Ollama

```
ollama serve
```

运行 `ollama serve --help` 可查看可设置的环境变量列表。
