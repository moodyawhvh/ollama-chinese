安装 Ollama,拿到你的第一个回复。

## 2. 打开菜单

在终端运行 `ollama`,打开交互式菜单:

```shell
ollama
```

通过菜单你可以:

- **运行模型** - 开启一段交互式对话
- **启动工具** - [Claude Code](/integrations/claude-code)、[OpenClaw](/integrations/openclaw)、[VS Code](/integrations/vscode) 等

## 3. 开始对话

运行一个模型,开启你的第一段对话。

```shell
ollama run gemma4
```

云端模型的用法完全一样:

```shell
ollama run gemma4:cloud
```

发送你的第一条消息:

```text
用一段话解释为什么天空是蓝色的。
```

输入以下命令退出对话:

```shell
/bye
```
